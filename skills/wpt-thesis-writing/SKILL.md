# 无线充电硕士论文写作

## 工作流

1. 确定用户要交付的内容、目标读者、篇幅和学校体例。以用户给出的提纲和模板为准。资料未齐时，从现有材料先写能成立的部分。
2. 写前明确本段或本章回答什么、从前文接收什么、需要哪项证据、要给后文留下什么。检查来源、算例、版本、工况、指标定义和比较对象。关键数值、公式及文献主张先定位原材料。原文、已确认内容、推断和建议分别处理。
3. 用材料支持主张。结果段按需要交代观察、差异、依据、解释及适用边界。保留改变结论的负面结果与比较条件。公式沿用源定义，说明符号、单位、假设和适用范围。保持文献条目、数值和测量状态的原义。
4. 核对段落和章节之间的术语、图表、参数、推导和主张是否相容。正文之外列出确有影响的待补证据、来源冲突或无法满足的压缩要求。可追溯的正文与工作备注分开。

| 任务 | 输出重点 |
| --- | --- |
| 大纲 | 各章问题、前置材料、拟用证据、预期产出及后续用途。让学校模板和研究材料决定章节顺序与数量。 |
| 起草整章 | 按章职责保留模型假设、关键推导、检测或求解条件、图表首次引用和小结。期刊稿可按体例安排附录。 |
| 修订正文 | 保留技术事实、公式、数值、引文及限定条件。修复术语漂移、证据跳跃或叙事重复。把修订后的正文交付给用户。用户明确要求写回、保存或覆盖指定文件时，才修改原文件。 |
| 压缩正文 | 先删重复背景、同义复述和低价值过程描述。保留理解模型与复现所需的推导和条件，必要时指出哪些细节可移至附录。 |

## 按需读取

普通段落润色优先使用给定文本。可直接处理时无需打开参考文件。若术语或写法不清，只读下面对应文件的相关段落或用户指定的术语条目。整章仅加载与章职责相关的模块，全文一致性检查沿任务涉及的章节与证据定位查读。

| 需要解决的问题 | 读什么 |
| --- | --- |
| 大纲、章节职能、推导在章内的位置、过渡或小结 | [学位论文组织与段落写作](references/thesis-structure.md) |
| 补偿网络、电池等效电路、公式推导或仿真材料 | [无线充电、电池建模与仿真](references/modeling-and-simulation.md) |
| 分段充电、优化问题、求解写法或对照设计 | [充电策略与联合优化](references/charging-and-optimization.md) |
| 样机、图表、定量结果、机理与证据边界 | [样机、图表、结果与证据](references/evidence-and-results.md) |
| 技术含义明确但表达不清，或用户需要改写例子 | [中文工科学术语言](references/chinese-academic-style.md)中对应场景 |
| 用户指定学位论文样本，或需要了解样本怎样组织素材 | [公开学位论文参考卡](references/thesis-reference-cards.md)中对应卡片 |

存在项目上下文时遵循项目说明。论证安排查对应章节映射。需核实结果时先定位研究协议和证据，再打开被引用的原报告。缺少项目索引时直接使用用户给定材料。来源冲突列出位置及影响。常规润色、局部改写不遍历研究项目。遵守项目、本轮授权和材料的处理范围，原件默认本地只读。

## 任务交接

显式要求专项核查时使用现有审读技能 `wpt-thesis-claim-review`。独立数值核验、仿真或作图交给 `scientific-toolkit-skill`，Word/PPT 交付交给 `office-academic-skill`。组合任务先澄清依赖，核验结果实际返回后才把它写入正文。交接未执行或未返回时保留待验证状态，以现有证据完成能写的部分。主写作入口可独立处理用户给出的正文材料。
